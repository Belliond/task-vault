GOOGLE CLASSROOM OFFLINE

Google Classroom

One-time setup with your own Google OAuth Client ID (free, ~2 minutes). Assignments with due dates are pulled straight from your enrolled Classroom courses. The token stays in this browser only.

One-time setup (Google Cloud Console): 1. Open console.cloud.google.com → create a project.
2. Enable Google Classroom API.
3. Credentials → Create OAuth client ID → Web application. Add these under Authorized JavaScript origins: https://belliond.github.io and Authorized redirect URIs: https://belliond.github.io/task-vault/
4. OAuth consent screen → External → Test users → add every Google account that will sync (yours and your friends').
5. Copy the Client ID (....apps.googleusercontent.com) below.
A Google window opens — pick the account that is enrolled in your classes and allow access. The window closes itself when the token is captured. If the popup is blocked, use the manual paste below. After allowing access you land on the Task Vault page with a long address. Copy the WHOLE address bar (Ctrl+L → Ctrl+C) and paste it below.
