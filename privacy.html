Ghost Task Matrix

Privacy Policy

Terakhir diperbarui: 13 November 2026

Ghost Task Matrix adalah aplikasi pengelola tugas kuliah yang berjalan sepenuhnya di browser. Halaman ini menjelaskan data apa yang diakses aplikasi, untuk apa data itu dipakai, dan di mana disimpan.

1. Data yang diakses

Aplikasi hanya mengakses data yang diperlukan untuk menampilkan tugas:

  • Google Classroom — daftar kelas yang Anda ikuti (classroom.courses.readonly) dan daftar tugas beserta tanggal pengumpulannya (classroom.coursework.me.readonly).
  • Moodle kampus — daftar mata kuliah dan daftar tugas, melalui token web service milik akun Anda sendiri.

Aplikasi tidak membaca email, file di Google Drive, kontak, nilai, atau isi pengumpulan tugas Anda. Aplikasi juga tidak pernah mengubah, menghapus, atau mengumpulkan tugas apa pun — semua izin yang diminta bersifat baca-saja.

2. Cara data dipakai

Data hanya dipakai untuk satu hal: menampilkan daftar tugas dan deadline di halaman aplikasi, lalu menyimpannya ke database agar tidak perlu diambil ulang setiap kali halaman dibuka.

Data tidak dijual, tidak dibagikan, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model apa pun.

3. Di mana data disimpan

  • Browser Anda — token akses Google disimpan di localStorage dan berlaku sekitar satu jam.
  • Database — judul tugas, nama kelas, dan tanggal deadline disimpan di Supabase. Isinya hanya data tugas, bukan isi akun Google atau Moodle Anda.

Aplikasi ini dipakai secara pribadi dan tidak memiliki sistem akun pengguna. Siapa pun yang memiliki tautan aplikasi dapat melihat daftar tugas yang tersimpan di database.

4. Token dan kredensial

Token Moodle dan refresh token Google hanya disimpan di sisi server (GitHub Secrets) dan tidak pernah dikirim ke browser. Yang tersimpan di browser hanyalah token akses berumur pendek.

5. Mencabut akses

Anda dapat menghentikan akses aplikasi kapan saja:

  • Google — buka myaccount.google.com/permissions, pilih aplikasi ini, lalu klik Remove access.
  • Moodle — buka halaman Security keys di akun Moodle Anda dan hapus token yang dipakai.
  • Browser — hapus data situs ini untuk membuang token yang tersimpan di localStorage.

6. Data pihak ketiga

Aplikasi memakai layanan berikut, masing-masing dengan kebijakan privasinya sendiri:

  • Google Classroom API — policies.google.com/privacy
  • Supabase — supabase.com/privacy
  • GitHub Pages — GitHub Privacy Statement

Penggunaan data yang diterima dari Google API oleh aplikasi ini tunduk pada Google API Services User Data Policy, termasuk ketentuan Limited Use.

7. Perubahan

Perubahan pada kebijakan ini akan diperbarui di halaman yang sama, dengan tanggal pembaruan di bagian atas.
